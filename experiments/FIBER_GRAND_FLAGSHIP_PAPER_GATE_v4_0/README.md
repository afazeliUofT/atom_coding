# FIBER-GRAND Flagship-Paper Gate v4.0

This package is the paper-readiness gate for the **narrow fixed-edit FIBER-GRAND track**. It does not revive the original broad random-transformation or new-guesswork claims.

## Frozen scientific claim

For a fixed number of uniformly located deletions followed by BSC substitutions on the surviving symbols, a membership-only aggregate inverse decoder can return the complete maximum-likelihood tie set with a strict unseen-candidate certificate. In an explicitly defined arbitrary-code L0 membership-oracle model, its distinct-candidate query count is polynomially competitive, and therefore exponent-optimal, for interior best-alignment mismatch shells. Fixed-edit history revelation additionally admits Renyi moment and large-deviation laws, producing different typical and mean complexity boundaries.

The theory dossier establishes and audits:

4. an oracle-relative query sandwich for FIBER;
5. candidate-query exponent optimality and polynomial competitiveness for fixed edit count and interior shells;
6. fixed-edit history moment and tail laws;

## Computational gate

The standard profile performs:

- exhaustive Python micro-world audits;
- exact finite-length moment/tail convergence checks through blocklength 2048;
- a C++20 `-O3` benchmark of membership-only FIBER against compiled exact systematic-code prefix A*;
- syndrome-trellis exactness self-tests and timing where the DP budget is feasible;
- random-linear and reproducible named-polynomial CRC-linear codes without a materialized codebook;
- blocklengths 32, 48, and 64, rates 0.75 and 0.875, and low substitution probabilities around the predicted operating boundaries;
- a true linear-time VT specialization boundary;
- an optional measured trace audit.

The timing results are reference implementations, not a hardware or universally optimized state-of-the-art comparison. The measured-trace gate is optional for a theory-centered IEEE TIT manuscript and mandatory for telecommunications or field-impact claims.
