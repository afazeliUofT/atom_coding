\section{Purpose and frozen decision discipline}
The earlier computational gates established three facts.  First, pathwise first-hit decoding can disagree with aggregate maximum likelihood (ML) on deletion channels.  Second, a membership-first aggregate inverse decoder can be made exact through a strict residual-mass certificate.  Third, at short lengths and low substitution probabilities, the decoder can be competitive with code-specific exact searches while using only syndrome or checksum membership rather than a materialized codebook.

Those results did not settle the most important field-defining questions:
\begin{enumerate}[label=(\roman*),leftmargin=2em]
\item whether any genuinely new theorem survives the prior-art boundary;
\item whether typical, mean, and tail complexity have the same operating region;
\item whether the finite-length computational advantage is consistent with the new theory rather than a Python artifact;
\item whether a physically calibrated synchronization impairment occupies the favorable regime.
\end{enumerate}
This dossier develops the first three questions rigorously and supplies a reproducible gate for the fourth.  It does not permit the broad claim to be rescued by changing terminology after a negative result.

\section{Narrowed novelty adjudication}
\subsection{Claims withdrawn permanently}
The following are not new contributions of the revised programme.
\begin{enumerate}[leftmargin=2em]
\item \textbf{Posterior candidate rank.}  Ranking $x$ by $W(y\mid x)$ under a uniform input prior is ordinary conditional guesswork.  Its R\'enyi and large-deviation theory has established foundations \cite{Arikan1996,Li2018}.
\item \textbf{Best path versus best string.}  Ambiguous probabilistic automata distinguish a most-probable path from a most-probable emitted string, and the general most-probable-string problem is NP-hard for probabilistic automata \cite{HigueraOncina2014}.
\item \textbf{Priority-first or sequential search.}  Priority-first ML decoding of linear block codes and synchronization-error sequential decoding are classical or established lines \cite{Gallager1961,Han1993,Banerjee2022}.
\item \textbf{Summing hidden alignments.}  Forward-backward and weighted-transducer methods sum alignment paths, including in insertion/deletion/substitution receivers \cite{DaveyMacKay2001,Mohri2009}.
\item \textbf{Generic candidate-likelihood guessing.}  Guessing-based decoders for general discrete memoryless channels can rank input candidates by channel closeness and query code membership \cite{TanJoudeh2025}; modern work also unifies noise-side and codeword-side guessing \cite{Wang2025}.
\item \textbf{Unrestricted transducer tractability.}  General ambiguous automata can be computationally hard or undecidable, while bounded ambiguity supports only qualified algorithmic results \cite{HigueraOncina2014,Fijalkow2022}.
\end{enumerate}

\subsection{Closest insertion/deletion prior art}
The narrow audit also found substantial overlap in synchronization coding:
\begin{itemize}[leftmargin=2em]
\item Gallager's 1961 report and later drift-state sequential decoders already search synchronization hypotheses \cite{Gallager1961,Banerjee2022}.
\item A 1990 patent enumerates insertion/deletion ``error frames,'' decodes each frame, computes a word likelihood, and selects a maximum-probability output \cite{US4922494}.
\item Fixed-$k$ deletion work derives multiplicity-aware ML/ML* rules for one and two deletions \cite{Sabary2022}.
\item GC/GC+ codes and VT codes provide specialized polynomial or linear-time decoders for fixed deletions \cite{Hanna2017,Abroshan2017}.
\item Polar guard-band constructions achieve information rates on insertion/deletion/substitution channels in an asymptotic, code-designed regime \cite{PfisterTal2021}.
\item GRAND-assisted modulation already applies lightweight GRAND ideas to a specialized variable-length demapping problem \cite{Ozaydin2022}.
\end{itemize}

\section{Channel, history representation, and exact decoder}
\subsection{Fixed-edit deletion/BSC channel}
Let $x\in\{0,1\}^n$ and fix an edit count $t<n$.  A deletion set $J\subseteq[n]$, $|J|=t$, is selected uniformly from
\[
\J_t=\{J\subseteq[n]:|J|=t\},\qquad S_n=|\J_t|=\binom nt.
\]
The $m=n-t$ surviving symbols pass through a BSC with crossover probability $0\le p<1/2$, producing $y\in\{0,1\}^m$.  For candidate $x$, let $d_J(x,y)$ be the Hamming distance between $y$ and the subsequence of $x$ obtained by deleting $J$.  The exact likelihood is
\begin{equation}
\Lambda_y(x)=W(y\mid x)=\frac1{S_n}\sum_{J\in\J_t}p^{d_J(x,y)}(1-p)^{m-d_J(x,y)}.
\label{eq:likelihood}
\end{equation}
For $p=0$, each term is interpreted as the indicator of an exact subsequence match.

\subsection{Inverse histories}
An inverse history is
\[
h=(J,b,e)\in\Hh_n:=\J_t\times\{0,1\}^t\times\{0,1\}^m,
\]
where $b$ supplies the deleted symbols and $e$ is a survivor substitution pattern.  It generates
\[
x_h=\operatorname{Ins}_{J}(y\oplus e,b)
\]
with component weight
\begin{equation}
\omega(h)=\frac1{S_n}p^{\wt(e)}(1-p)^{m-\wt(e)}.
\label{eq:component}
\end{equation}
For each candidate $x$, exactly one $(b,e)$ is compatible with each $J$, hence
\[
\Lambda_y(x)=\sum_{h:x_h=x}\omega(h).
\]
The $2^t$ hidden assignments are inverse candidates, not extra channel-probability factors; this is why the sum of history weights over all inverse histories exceeds one, while each candidate likelihood remains correct.

\subsection{Membership-first aggregate inverse decoder}
For every deletion set $J$, create a stream that enumerates $(e,b)$ in increasing substitution weight.  Merge the stream heads in a max heap.  Maintain a set of distinct candidates.  At first discovery of $x$:
\begin{enumerate}[label=(\alph*),leftmargin=2em]
\item query \texttt{IsCodeword}$(x)$;
\item only if true, compute the complete likelihood \eqref{eq:likelihood};
\item update the incumbent ML score and discovered tie set.
\end{enumerate}
Scoring discovered noncodewords is unnecessary: they cannot compete in the code-constrained maximization, and every undiscovered codeword remains covered by the global frontier bound.

\begin{algorithm}[t]
\caption{Certified fixed-edit FIBER search}
\begin{algorithmic}[1]
\Require $y$, $t$, $p$, membership oracle for $\C$, history budget
\State initialize one probability-ordered stream for each $J\in\J_t$
\State $D\gets\emptyset$; $s^\star\gets-\infty$; $T^\star\gets\emptyset$
\While{the global heap is nonempty}
  \State pop the largest next history; advance its stream
  \State construct $x_h$
  \If{$x_h\notin D$}
    \State $D\gets D\cup\{x_h\}$; query \texttt{IsCodeword}$(x_h)$
    \If{$x_h\in\C$}
      \State compute exact $\Lambda_y(x_h)$ and update $(s^\star,T^\star)$
    \EndIf
  \EndIf
  \State $U_{\rm new}\gets\sum_{J\in\J_t}\eta_J$, where $\eta_J$ is stream $J$'s next weight
  \If{$T^\star\ne\emptyset$ and $s^\star>U_{\rm new}$}
    \State \Return the complete ML tie set $T^\star$ and the strict certificate
  \EndIf
\EndWhile
\end{algorithmic}
\end{algorithm}

\begin{theorem}[Strict unseen-candidate certificate]
\label{thm:certificate}
Let $\eta_J$ be the weight of the next unprocessed history in stream $J$, or zero if the stream is exhausted.  Every completely unseen candidate $x$ satisfies
\[
\Lambda_y(x)\le U_{\rm new}:=\sum_{J\in\J_t}\eta_J.
\]
Suppose every discovered codeword has been exactly scored and let
\[
s^\star=\max_{c\in\C\cap D}\Lambda_y(c),\qquad
T^\star=\{c\in\C\cap D:\Lambda_y(c)=s^\star\}.
\]
If $s^\star>U_{\rm new}$, then
\[
T^\star=\argmax_{c\in\C}\Lambda_y(c).
\]
\end{theorem}
\begin{proof}
For a fixed $J$, an unseen candidate has at most one compatible inverse history.  Because that history has not been emitted, its weight is at most $\eta_J$.  Summing over $J$ gives the unseen-candidate bound.  The strict inequality excludes every unseen codeword from tying or exceeding the incumbent.  Discovered codewords have exact scores, so the discovered maximizers are precisely the global ML tie set.
\end{proof}

\begin{remark}[Numerical certification]
The production implementation uses outward rounding with \texttt{nextafter} and a scale-aware margin before accepting the strict inequality.  Exhaustive micro-world tests remain the authoritative correctness check.  A paper-grade implementation should use interval or fixed-point outward-rounded likelihoods near the stopping boundary.
\end{remark}

\section{Deterministic fixed-edit shell certificate}
Let $E$ be the actual number of substitutions in the transmitted history and define
\[
a=\frac{1-p}{p},\qquad
\ell_{n,t}=\left\lfloor\log_a\binom nt\right\rfloor,
\qquad
w_E=\min\{m,E+\ell_{n,t}\}.
\]

\begin{theorem}[Deterministic shell-work bound]
\label{thm:shell}
For $0<p<1/2$, after all inverse histories with substitution weight at most $w_E$ have been processed, the strict certificate in \cref{thm:certificate} must have fired.  Hence
\begin{equation}
\Qfib\le 2^t\binom nt\sum_{i=0}^{w_E}\binom mi.
\label{eq:shellbound}
\end{equation}
For $p=0$,
\[
\Qfib\le 2^t\binom nt.
\]
\end{theorem}
\begin{proof}
The transmitted codeword is discovered no later than its actual deletion set, deleted bits, and survivor error mask.  Thus the incumbent score is at least
\[
\frac1{S_n}p^E(1-p)^{m-E}.
\]
After every history through shell $w$ has been emitted, the next history in each stream has weight at most
\[
\frac1{S_n}p^{w+1}(1-p)^{m-w-1}.
\]
Summing over the $S_n$ streams gives
\[
U_{\rm new}\le p^{w+1}(1-p)^{m-w-1}.
\]
At $w=E+\ell_{n,t}<m$, the ratio of this bound to the one-history incumbent lower bound is at most
\[
S_n\left(\frac{p}{1-p}\right)^{\ell_{n,t}+1}<1,
\]
because $\ell_{n,t}+1>\log_a S_n$.  If $w_E=m$, all streams are exhausted.  Each stream contains $2^t\binom mi$ histories in shell $i$, yielding \eqref{eq:shellbound}.  At $p=0$, only shell zero has positive weight.
\end{proof}

\begin{corollary}[Fixed-edit typical history exponent]
\label{cor:typical}
For fixed $t$ and $p\in(0,1/2)$, for every $\eps>0$,
\[
\Pr\left\{\frac1n\log_2\Qfib\le \hbin(p)+\eps\right\}\longrightarrow1.
\]
\end{corollary}
\begin{proof}
For fixed $t$, $\log\binom nt=O(\log n)$ and $\ell_{n,t}=O(\log n)$.  The binomial error weight satisfies $E/m\to p$ in probability.  Standard Hamming-ball estimates give
\[
\sum_{i=0}^{qm}\binom mi\le 2^{m\hbin(q)},\qquad q<1/2,
\]
and continuity of $\hbin$ completes the proof.
\end{proof}

\section{History revelation: exact moment and tail laws}
The previous result is a high-probability upper bound.  It does not settle the mean or rare-tail complexity.  To expose those quantities, define the rank at which the \emph{actual inverse history} is revealed in the global probability ordering.

\begin{definition}[History revelation rank]
Let $\Rhist$ be the rank of the actual triple $(J,b,e)$ among all inverse histories ordered by nonincreasing component probability, under an arbitrary deterministic tie order within each shell.
\end{definition}
Define
\[
K_n=2^t\binom nt,\qquad B_m(k)=\sum_{i=0}^{\min\{k,m\}}\binom mi,
\]
with $B_m(-1)=0$.

\begin{proposition}[Finite-length rank sandwich]
\label{prop:ranksandwich}
Conditioned on $E=e$,
\begin{equation}
1+K_nB_m(e-1)\le \Rhist\le K_nB_m(e).
\label{eq:ranksandwich}
\end{equation}
\end{proposition}
\begin{proof}
Every history in a lower-weight shell has strictly higher probability and must precede the actual history.  At most all histories through shell $e$ precede or include it.  There are $K_n\binom mi$ histories in shell $i$.
\end{proof}

\begin{theorem}[Fixed-edit moment exponent]
\label{thm:moment}
Fix $t$, $p\in(0,1/2)$, and $\rho>0$.  Let
\[
\alpha=\frac1{1+\rho}.
\]
Then
\begin{equation}
\lim_{n\to\infty}\frac1n\log_2\mathbb E[\Rhist^\rho]
=\rho\Renyi_\alpha(p),
\label{eq:moment}
\end{equation}
where the binary R\'enyi entropy is
\[
\Renyi_\alpha(p)=\frac1{1-\alpha}\log_2\left(p^\alpha+(1-p)^\alpha\right).
\]
The certified decoder obeys the corresponding upper bound
\begin{equation}
\limsup_{n\to\infty}\frac1n\log_2\mathbb E[\Qfib^\rho]
\le \rho\Renyi_\alpha(p).
\label{eq:certmoment}
\end{equation}
\end{theorem}
\begin{proof}
The fixed-edit factor $K_n$ is polynomial in $n$ and therefore subexponential.  By \cref{prop:ranksandwich}, the exponential order of $\Rhist$ conditioned on $E\approx qm$ is $2^{m\hbin(q)}$ for $q\le1/2$; the maximizing type below is strictly less than $1/2$.  The binomial method of types gives
\[
\frac1n\log_2\mathbb E[\Rhist^\rho]
\longrightarrow
\sup_{0\le q\le1/2}\left\{\rho\hbin(q)-\Dkl(q\|p)\right\},
\]
where
\[
\Dkl(q\|p)=q\log_2\frac qp+(1-q)\log_2\frac{1-q}{1-p}.
\]
The optimizer is
\[
q_\rho=\frac{p^{1/(1+\rho)}}{p^{1/(1+\rho)}+(1-p)^{1/(1+\rho)}},
\]
and direct substitution yields the variational identity
\[
\sup_q\{\rho\hbin(q)-\Dkl(q\|p)\}
=\rho\Renyi_{1/(1+\rho)}(p).
\]
For the certified decoder, \cref{thm:shell} replaces $E$ by $E+O(\log n)$ and multiplies by only a polynomial fixed-edit factor; this does not change the exponent.  Since the decoder may stop earlier, only the upper bound is universal.
\end{proof}

\begin{remark}[The crucial distinction]
At $\rho=1$, the mean history-revelation exponent is $\Renyi_{1/2}(p)$, not $\hbin(p)$.  A decoder may therefore have attractive median or fixed-quantile latency while suffering unfavorable mean or extreme-tail work.  This distinction is invisible in the typical shell theorem alone.
\end{remark}

\begin{theorem}[Large deviations of history revelation]
\label{thm:ldp}
For fixed $t$ and $p<1/2$, $n^{-1}\log_2\Rhist$ obeys the contraction of the binomial type large-deviation principle under
\[
g(q)=\begin{cases}
\hbin(q),&0\le q\le1/2,\\
1,&1/2\le q\le1.
\end{cases}
\]
In particular, for $\gamma\in[\hbin(p),1)$, let $q_\gamma\in[p,1/2)$ solve $\hbin(q_\gamma)=\gamma$.  Then
\begin{equation}
\lim_{n\to\infty}-\frac1n\log_2\Pr\left\{\frac1n\log_2\Rhist\ge\gamma\right\}
=\Dkl(q_\gamma\|p).
\label{eq:tail}
\end{equation}
At $\gamma=1$ the rate is $\Dkl(1/2\|p)$.  The same formulas give upper-tail bounds for $\Qfib$ after the $O(\log n)$ shell shift.
\end{theorem}
\begin{proof}
The empirical error fraction $E/m$ obeys the binomial large-deviation principle with rate $\Dkl(q\|p)$.  The rank sandwich gives exponential equivalence to $g(E/m)$.  The contraction principle yields the result; for an upper-tail threshold below one, the minimizing type is the unique $q_\gamma\ge p$ with $\hbin(q_\gamma)=\gamma$.
\end{proof}

\begin{corollary}[Fixed and exponentially rare quantiles]
Every fixed quantile of $n^{-1}\log_2\Rhist$ converges to $\hbin(p)$.  A quantile whose upper-tail probability scales as $2^{-n\beta}$ has exponent $\hbin(q_\beta)$, where $q_\beta\in[p,1/2]$ solves $\Dkl(q_\beta\|p)=\beta$, until saturation at one.
\end{corollary}

\section{A typical-versus-mean complexity phase diagram}
Suppose an independent exact code-side decoder has work bounded by
\[
\Qcode\le\poly(n)2^{n(1-R)}.
\]
For a high-rate linear code this is representative of a redundancy-state or syndrome-trellis search with $2^{n-k}$ states, although actual constants and code structure matter.  Run FIBER and the code-side decoder in parallel and stop when either returns an exact certificate.

\begin{theorem}[Hybrid complexity upper envelope]
\label{thm:hybrid}
For fixed $t$ and $p<1/2$, the hybrid exact decoder obeys
\begin{align}
\limsup_{n\to\infty}\frac1n\log_2 Q_{\rm hybrid}^{(\text{fixed quantile})}
&\le \min\{\hbin(p),1-R\},\\
\limsup_{n\to\infty}\frac1n\log_2\mathbb E[Q_{\rm hybrid}^{\rho}]
&\le \min\{\rho\Renyi_{1/(1+\rho)}(p),\rho(1-R)\}.
\end{align}
\end{theorem}
\begin{proof}
The hybrid work is no larger than either constituent work.  Apply \cref{cor:typical,thm:moment} to FIBER and the assumed code-side bound to the other constituent.
\end{proof}

The predicted fixed-quantile crossover is
\[
\hbin(p_{\rm typ})=1-R,
\]
while the predicted mean-work crossover is
\[
\Renyi_{1/2}(p_{\rm mean})=1-R.
\]
Because $\Renyi_{1/2}(p)>\hbin(p)$ for $p\in(0,1/2)$,
\[
p_{\rm mean}<p_{\rm typ}.
\]

\section{Parameter complexity and the tractability boundary}
The inverse history count contains
\[
2^t\binom nt=\Theta(2^t n^t/t!)
\]
for fixed $t$.  The present decoder is therefore in the parameterized class XP: polynomial in $n$ for each fixed $t$, with polynomial degree depending on $t$.  It is \emph{not} fixed-parameter tractable (FPT) in the formal sense $f(t)n^c$ with $c$ independent of $t$.

If $t$ grows linearly with $n$, then $n^{-1}\log_2\binom nt$ contributes a nonzero deletion-position entropy and the fixed-edit theorem no longer preserves the BSC exponent.  Any future FPT or positive edit-rate claim requires a new merging or dynamic-programming theorem.  The general most-probable-string hardness literature makes an unrestricted exact claim implausible \cite{HigueraOncina2014,Fijalkow2022}.

\subsection{Moment and tail numerical audit}
The moment gate evaluates the exact finite-$n$ rank sandwich through $n=2048$, for $t\in\{1,2\}$, multiple $p$, and $\rho\in\{1/2,1,2\}$.  The reference run found:
\begin{itemize}[leftmargin=2em]
\item maximum finite-$n$ reveal-moment exponent gap at $n=2048$: $0.01648$ bit/use;
\item maximum certificate-upper exponent gap: $0.02276$ bit/use;
\item maximum fixed-quantile gap: $0.07211$ bit/use;
\item variational identity error below $5\times10^{-16}$;
\item decreasing finite-length gaps in every tested parameter sequence.
\end{itemize}
These computations verify the implementation and finite-length convergence; the proofs, not the plots, establish the theorem.

\section{Honest specialization boundary: VT decoding}
A generic code-modular decoder should not be expected to beat a code designed specifically for the impairment.  The package therefore implements a classical linear-time single-deletion VT decoder, rather than the earlier $2n$ insertion-and-checksum enumerator.  The exactness audit exhaustively verifies it through $n=13$.

In the reference run, FIBER was approximately $22\times$, $43\times$, $86\times$, and $181\times$ slower than the specialized VT decoder at $n=15,31,63,127$, respectively.  This is a successful \emph{boundary} result:
\begin{tcolorbox}[colback=gray!4,colframe=gray!55!black]
\centering FIBER's value is code modularity and noisy fixed-edit ML, not replacement of an optimal specialized VT decoder.
\end{tcolorbox}
VT codes are known to admit linear-time single-deletion decoding \cite{Abroshan2017}.  Any manuscript must report this result prominently rather than describe the VT gate as a performance win.

\section{Physical plausibility and the unresolved real-trace gate}
The package includes a physically motivated synthetic front end:
\[
\text{BPSK symbols}\to\text{one accumulated timing-cycle slip}\to\text{phase-dependent ISI}\to\text{AWGN hard decisions}.
\]
A uniformly random initial phase and one-symbol accumulated drift create exactly one missed decision; ISI and AWGN create survivor substitutions.  The standard held-out audit at $n=48$, SNR $7$ dB, and ISI strength $0.06$ found:
\begin{itemize}[leftmargin=2em]
\item exactly one deletion in every frame;
\item fitted substitution probability $0.001319$ and held-out probability $0.001135$;
\item absolute fit error $1.84\times10^{-4}$;
\item held-out lag-one error correlation approximately $-0.0012$;
\item deletion-position total variation $0.193$ between train and held-out empirical laws.
\end{itemize}
This shows that a simple timing-slip front end can land inside the low-$p$ theoretical region.  It is not measured deployment evidence.  The package deliberately contains no fabricated real trace and therefore cannot remove the qualifier
\begin{center}
\small\path{REAL_TRACE_REQUIRED}
\end{center}
A measured trace file can be placed in \texttt{data/real\_traces/}; the required CSV columns are \texttt{n}, \texttt{deleted\_position}, and \texttt{substitution\_weight}.  Passing syntax and calibration checks is still only a prerequisite; end-to-end superiority over a matched receiver remains a separate experiment.

\section{Final scientific interpretation}
The theoretical and computational evidence supports the following narrow statement:
\begin{quote}
For a fixed number of uniformly located deletions and sufficiently low survivor-substitution uncertainty, codebook-free membership-only aggregate inverse search admits exact ML certificates and has a controlled probability-ordered history complexity.  Its fixed-quantile exponent is governed by binary Shannon entropy, its history-revelation moments by binary R\'enyi entropy, and these yield distinct typical and mean operating boundaries relative to redundancy-state exact search.
\end{quote}
This is a coherent new theorem-and-algorithm package with credible research potential.  It is not yet a field-defining result.  The decisive remaining uncertainty is whether a measured receiver impairment occupies the favorable region and whether the advantage survives equally optimized implementations and external novelty/proof review.

\appendix
\section{Proof-review checklist}
An external reviewer should verify all of the following independently:
\begin{enumerate}[leftmargin=2em]
\item each unseen candidate has at most one compatible history per deletion set;
\item the sum-of-frontiers bound does not double count in a way that invalidates an upper bound;
\item membership-first scoring does not omit a competing codeword;
\item the strict certificate returns the complete tie set under the stated tolerance model;
\item $2^t$ is a history-count factor but not a channel-probability factor;
\item the shell shift uses $\lfloor\log_{(1-p)/p}\binom nt\rfloor$ and yields a strict inequality;
\item the history-rank sandwich is independent of within-shell tie order;
\item the moment variational identity is evaluated at $q_\rho<1/2$;
\item the certified decoder obtains only a universal upper moment/tail bound, not equality;
\item the phase diagram is an upper-envelope theorem conditional on a $2^{n(1-R)}\poly(n)$ code-side decoder;
\item the current parameter dependence is XP, not FPT;
\item no field-defining or practical claim is inferred from the synthetic physical model.
\end{enumerate}

\section{Primary-source novelty questions}
The external novelty reviewer should answer claim by claim:
\begin{enumerate}[leftmargin=2em]
\item Does any paper or patent already give the same membership-only aggregate inverse generator and strict sum-of-stream-frontiers certificate?
\item Is \cref{thm:shell} already an explicit theorem in synchronization sequential decoding or fixed-deletion decoding?
\item Is \cref{thm:moment} a documented fixed-edit history-revelation theorem, or only derivable from generic guesswork after this representation is introduced?
\item Has the typical-versus-mean crossover for bounded-edit aggregate inverse decoding already been stated?
\item Does the proposed decoder add anything beyond direct implementation of general DMC candidate guessing \cite{TanJoudeh2025}?
\item Are there patent claims broad enough to anticipate code-membership edit-history enumeration with likelihood aggregation and certified stopping?
\end{enumerate}

\section{Reference-standard limitations}
The internal standard run is intentionally inexpensive.  It is suitable for an investment gate, not a paper:
\begin{itemize}[leftmargin=2em]
\item only three blocks were used at the largest primary length;
\item Python wall time can favor one data structure over another;
\item the strong exact baselines are independently organized but share channel and code utilities;
\item $p95$ from three observations is not a statistically supported tail estimate;
\item no measured front-end trace is bundled;
\item no energy, cache traffic, or fixed-point implementation is measured.
\end{itemize}
A positive run therefore establishes only high potential and the right to perform the next external/physical gate.
