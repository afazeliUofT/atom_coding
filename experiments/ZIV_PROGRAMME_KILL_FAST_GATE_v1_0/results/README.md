# Generated results

The launcher clears this directory except for this README, then executes the frozen `standard` profile.

The authoritative files after a completed run are:

- `GATE_VERDICT.json`
- `GATE_REPORT.md`
- `ANALYSIS_HANDOFF.md`
- exactly one of `STOP_COMMAND.txt`, `PIVOT_COMMAND.txt`, or `CONTINUE_COMMAND.txt`
- `RESULTS_SHA256.txt`

The release's independently generated reference-standard results are retained under `validation/reference_standard_run/`.
